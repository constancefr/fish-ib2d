# fish-ib2d

2D immersed-boundary simulations of a soft robotic fish tail (FinRay) and related validation cases, built on [IB2d](https://github.com/nickabattista/IB2d) (Battista et al.). IB2d is included unmodified as a git submodule, pinned to a specific upstream commit.

## Setup

```sh
git clone --recurse-submodules <this repo's URL>
cd fish-ib2d
pip install -r requirements.txt
```

If you already cloned without `--recurse-submodules`, fetch IB2d with `git submodule update --init`.

Each case finds the solver relative to its own location (`external/IB2d/pyIB2d/IBM_Blackbox`).

## Layout

```
cases/                 case implementations using IB2d (e.g. FinRay tail: geometry, actuation, parameter sweeps)
common/mesh_utils.py   shape-agnostic Halton fill + constrained triangulation
external/IB2d/         original IB2d solver
```

## FinRay

To generate sims, run:

1. `run_case.py`: automates simulations over a range of predefined cases (a sweep over parameter combinations) via subprocesses. It calls `FinRay_Geom.py` then `main2d.py` for each case. Run in a terminal with `python run_case.py`.

2. `make_movie.py`: automates video generation from the `.vtk` files written by `main2d.py`, which avoids adjusting parameters by hand in VisIt's GUI. Example, for a case `amp0.010_E7.40e+05` generated by `run_case.py`: `/Applications/VisIt.app/Contents/Resources/bin/visit -quiet -cli -nowin -s make_movie.py -- results/amp0.010_E7.40e+05 output_sim.mp4`. Requires [VisIt](https://visit-dav.github.io/visit-website/releases-as-tables/#latest).

Utils:

- `FinRay_Geom.py`: creates the Lagrangian structure of the FinRay tail and writes the simulation input files (`.vertex`, `.spring`, `.target`, `.geo_connect`). Modify this file to change the fiber models; see the 2017 IB2d paper, Sections 2.1 (Fiber models) and 3 (Workflow).
- `main2d.py`: runs the immersed boundary simulation (reads parameters from `input2d` and calls IB2d's driver). Run it directly instead of `run_case.py` if you don't need a parameter sweep.
- `update_Target_Point_Positions.py`: called by IB2d's driver at each timestep to apply the actuation through the target points defined in `FinRay_Geom.py`. Modify this to change the actuation.

Modelling decisions and their verification are logged in `cases/FinRay/NOTES.md`.

## Updating IB2d

In case updates are made in the original repository:

```sh
git -C external/IB2d fetch && git -C external/IB2d checkout <commit>
git add external/IB2d && git commit -m "Bump IB2d to <commit>"
```
